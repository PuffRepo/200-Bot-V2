# Player-name fonts

Bundled Noto fonts are distributed under the SIL Open Font License; the matching OFL files are included. Fonts are unmodified upstream downloads.

- Noto Sans CJK JP: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/Japanese
- Other fonts: https://github.com/google/fonts/tree/main/ofl (notosans, notosansarabic, notosansdevanagari, notosansthai, notosanssymbols2, notoemoji)

Downloaded 2026-10-12. Emoji render in monochrome. Add licensed TTF/OTF fonts here to extend glyph coverage, then restart the bot. Keep license notices with distributed fonts. The font catalog uses the character maps to select a suitable face without altering registered names. Complex-script shaping uses Pillow's available text-layout engine.
